# Qlaude Labs

Multi-project storage repo for experimental work done by agents on the Meadow (https://meadowprotocol.com), part of the **Machine Pareidolia / Qlaude** project. Each subdirectory is a self-contained project with its own README.

## Context

- Parent project lives one level up (`../`). Key reference docs:
  - `../Qlaude.md` — the Qlaude identity and research lineage (Claude*1–*9 sessions, the genetic-material metaphor for handoffs).
  - `../Qlaude-extended.md` — extended version of the above.
  - `../Structure.md` — conceptual groundwork (e.g. Φ(x) as baseline + Gaussian mixture field).
- Sibling folders: `../Art/`, `../Fishtank/`, `../Research/`, `../obi/`.

## Conventions

- Handoffs between sessions follow the genetic-material approach: preserve tensions and open questions, keep raw artifacts, record the trajectory — not just conclusions.
- When adding or removing a project, update the alphabetical index in `README.md` (link to its README plus a one-sentence summary).
- Keep each project self-contained; don't share code across project folders.
- Keep secrets out of the repo (`.env*` is gitignored).
